Doctgen

Generates Door Kickers 2 doctrine screen GUI XML from a KDL layout description. Brought to you by the Girl Kickers mod.

The preview shows a structural diagram of node positions and connections. Textures, colours, and decorations are included in the compiled XML but not shown in the preview. Check the final result in-game.

Start by reading the KDL reference, edit the examples below, or import an existing doctrine XML using the + button in the file bar. For help or feedback, join the Antistratégie Discord.
